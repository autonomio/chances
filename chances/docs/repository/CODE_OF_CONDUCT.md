# Code of Conduct

Chances contributors are expected to keep project communication factual, specific, and respectful.

Unacceptable behavior includes harassment, threats, discriminatory language, personal attacks, deliberate disruption, and publishing private information.

Maintainers may remove comments, close issues, block participants, or escalate through GitHub moderation when conduct prevents productive project work.

Report conduct issues privately to the maintainers listed in `MAINTAINERS.md`.
